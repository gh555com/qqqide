# Contributing

Thanks for your interest in qqqide!

## What this repository is

This repository is the **runtime source** of the qqqide client (IDE payload +
Electron shell + build scripts), published so the code can be audited — see
`LICENSE` ("Source Code Public & Auditable"). It is not a community project, and
we are **not accepting external pull requests** at this time.

## Welcomed contributions

- **Security vulnerability reports** — see `SECURITY.md`. These are genuinely
  valuable to us and are handled with priority.
- **Reproducible bug reports** — via the support contact in the app's Help menu
  or `29492511@qq.com`. Please include: version (bottom-left of the app), steps
  to reproduce, expected vs. actual behavior.

## Not accepted

- Feature / refactoring pull requests — the codebase follows specific internal
  conventions and we can't merge outside implementations.
- Translation pull requests — UI translations are managed from a single source of
  truth (Simplified Chinese) through an automated pipeline.

We read everything that comes in, even when we can't act on all of it promptly.
