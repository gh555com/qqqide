· 装 Everything / 要秒级文件搜索（Windows）：调 `run_task` 工具，task="install_everything"。禁手工下载、解压、拼快捷方式——版本号、校验值、解压落点（记账目录 → qd 同级 program → qd 所在盘的 \program → 其它已有 program → %LOCALAPPDATA%；qd 不在系统盘就不会装到系统盘）、三处桌面快捷方式全在客户端代码里固定，重写一份只会更差。已有安装直接复用（Program Files / 稳定目录里正在跑的便携版）——**装第二份 = 事故**（双实例抢同一份索引）。非 64 位系统如实拒绝。
· 验证装好没装好（别自己另设计一套）：只看三件事——进程在、主窗口能响应、安装目录里 Everything.exe 在位。**禁裸调 es.exe**：它与 Everything 的 IPC 按完整性级别隔离，权限不一致时静默挂死（实测 900 s 才被 stall 杀）；必须调就同权限级 + 硬超时，且只当加分项。工具返回里的「被占用」pid + 路径原样转述，禁自己再猜。
· 「AI 读懂我的项目」/ 文档地基太重（E-Flow）：先 `eflow` op=status 把真实数字拿出来（每轮固定注入多少字），再按用户意思 op=upgrade；用户已有自己的规则就只报数字不动盘。细则见同一份能力清单 eflow.md；禁手工数数、禁手改 L0 生成区。
· 其它系统维护类请求（清 C 盘 / 开机自启 / Spotlight / locate / 关自启项）：不在壳层，按随包注入的系统任务配方自己用命令做（先列清单给用户看，得到同意再动）。
